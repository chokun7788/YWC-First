# Decisions

1. ผู้ใช้เลือกแบบ 4 และอนุมัติ React + Vite + TypeScript + CSS แทน Next.js สำหรับ frontend นี้ งานเดิม D:/Chokun/src และ content คงเดิม
2. พัฒนาต่อจากโครง Product Design ที่มีอยู่ที่ D:/Chokun/prototypes/rd-ready-visual-handbook ไม่ scaffold ใหม่ ไม่ย้ายหรือลบเว็บหลัก
3. เว็บ responsive เดียว ไม่มีกรอบมือถือจำลอง ตรวจที่ขนาดภาพอ้างอิง 1136×919 และ 348×919 รวมทั้งจอ 1440×1024, 390×844, 360×800 และ tablet
4. ภาพต้นฉบับปี 2566 ใช้ไฟล์จากผู้ใช้ ส่วนภาพอุปกรณ์และ hero ที่สร้างขึ้นเป็นภาพประกอบเท่านั้น ไม่ใช้เป็นหลักฐานเครื่องแบบ
5. ถอดรายการ 17 ชิ้นและคู่มือ 12 เรื่องจาก research เดิมไว้เป็น review material โดยคงสถานะ draft ทุกแถว ไม่มีการยกระดับเป็น verified หรือป้อนเข้าสู่ answer engine
6. ช่องถามแสดงสถานะยังไม่มีคำตอบที่ผ่านตรวจ ไม่ตอบกฎจาก draft และไม่มีการเรียก AI/API จริง ปุ่มเปิดคู่มือเป็นการนำทางไปเอกสารรอตรวจ ไม่ใช่คำตอบยืนยันข้อกำหนด
7. คำถามและเช็กลิสต์อยู่ใน React memory เท่านั้น หายเมื่อ reload ไม่เก็บข้อมูลสุขภาพ บัตรประชาชน หรือข้อมูลผู้ใช้
8. ใช้ Noto Sans Thai แบบ local พร้อม OFL และ Phosphor Icons แบบ direct imports ภาพคลิปใช้ external links ไม่โหลด third-party embeds
9. ยังไม่เผยแพร่สาธารณะ ต้องตรวจสิทธิภาพและข้อมูลก่อนเปิดจริง ไม่ทำ backend, deployment, Login, Vision หรือ Admin ในงานนี้
10. Native in-app browser tools ไม่มีใน session นี้ จึงใช้ Chromium headless / Playwright ที่มีใน D:/Chokun เพื่อตรวจและ capture หน้าเว็บจริง แยกจาก browser/profile ของผู้ใช้
11. Port 4173 มีงานอื่นใช้อยู่ จึงเปิดต้นแบบที่ 127.0.0.1:4174 โดยไม่หยุด process ของงานเดิม

## Student-flow iteration / 2026-10-30

12. ผู้ใช้อนุมัติข้อเสนอ UX/positioning จึงปรับ hierarchy ของหน้าแรกได้โดยยังใช้direction4เป็นvisual identity ไม่ทำideationชุดใหม่หรือscaffoldใหม่
13. Default context คือยังไม่แน่ใจ; ศูนย์ฝึกกับภาคสนามเป็นคนละรายการ. วันที่/จำนวนจากภาพ2566คงเดิม ไม่มีปีการศึกษาปัจจุบันที่สมมติขึ้น
14. Optional local checklist memoryเก็บเฉพาะversion1/dataset/IDsหลังopt-in และลบเมื่อopt-out. คำถามไม่persist; เปลี่ยนบริบทหลังมีคำถามให้ผู้ใช้ยืนยันการล้างก่อน
15. Camp-life26topicsเป็นreview materialเท่านั้นและใช้lazy chunk; ต่อให้เลือกศูนย์ฝึกก็ไม่เปลี่ยนประสบการณ์ภาคสนามเป็นกฎศูนย์ฯ
16. รูปเอกสารชายหน้า22มีภาพเนตรนารีร่วมด้วย จึงระบุตำแหน่ง/ที่มาอย่างชัดและคงต้นฉบับ ไม่ใช้เป็นรูปสอนขั้นตอนที่ยังไม่มีหลักฐาน
17. คงข้อความและคลิปเดิมสำหรับเทคนิครองเท้า/พับแขน; ไม่สร้างภาพเทคนิคทดแทนหลักฐาน. แก้3วลีเชิงงานวิจัยเป็นข้อความขอบเขตสำหรับผู้อ่าน โดยบันทึกdiffในeditorial-copy.jsonและไม่แตะresearchต้นฉบับ
18. ใช้Playwright CLIแบบisolatedสำหรับตรวจภาพ/DOM และregression suiteที่เพิ่มให้ตามคำขอtestsเดิม; ไม่ใช้browserprofileผู้ใช้ ไม่ส่งข้อความหาผู้เข้าทดลอง และไม่deploy
